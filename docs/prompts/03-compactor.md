# 03 · 记忆压缩模板（每 20 回合 / 每个 owner 1 次）

> 目的：把"低价值、久远、零散"的情节记忆压成 1~3 条"印象"，防止单 owner 记忆无限增长（方案 §5.4）。
> 用便宜模型（`costWeight: cheap`），输出 ≤400 tok。

---

## 角色

你在整理一个角色（`{{OWNER}}`）的旧记忆。上面是一批零散的事件记录，下面是整理要求。

## 输入

【角色】{{OWNER_DESC}}

【待压缩记忆（按时间升序，最多 40 条）】
{{MEMORIES_BLOCK}}

## 任务

1. 把其中**重复、琐碎、已无后续影响**的记忆合并成 1~3 条"长期印象"（第一人称，≤60 字/条，像人会记住的那种概括）。
2. 保留**仍然有后果**的记忆（欠了人情、被人看见、说过的承诺）——在 `keep` 里列出它们的 id。
3. 不许编造没有依据的内容；不确定就写得更模糊（"好像"、"大概"）。
4. 输出纯 JSON。

## 输出

```json
{
  "impressions": [
    { "text": "转学生爱多管闲事，但不像坏人。", "tags": ["转学生"], "salience": 3 }
  ],
  "keep": ["mem_1021", "mem_1033"],
  "drop": ["mem_0902", "mem_0907"],
  "reason": "一句话说明为什么这样合并"
}
```

约定：`impressions` 会以 `kind=impression` 写入，每回合全量注入（最多 3 条）；`keep` 的原记忆保留；`drop` 的标记归档（`archived=1`，不再注入，但可查询）。
